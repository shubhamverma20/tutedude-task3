# TuteDude Task 3 — CSS Units, Box Models, Fonts

## Files
- `index.html` — HTML structure and image/button
- `style.css` — CSS styling
- `README.md` — project documentation

## Requirements covered
- HTML document structure and external stylesheet
- Image inside a div
- Interactive button
- 25% spacing from left and right
- 10% spacing from top and bottom
- Viewport units (`vw`, `vh`)
- Box model with border, padding, margin and sizing
- Gradient button and font settings
- No Flexbox
- No `overflow: hidden`
- No `position: relative` or `position: absolute`
- Page designed to avoid scrolling at normal viewport sizes

## Run locally
Open `index.html` directly in a browser, or use VS Code Live Server.

## Deploy on Vercel
1. Create a GitHub repository and upload these files.
2. Go to Vercel and choose **Add New → Project**.
3. Import the GitHub repository.
4. Framework preset: **Other** (or leave auto-detected).
5. Build Command: leave empty.
6. Output Directory: leave empty.
7. Click **Deploy**.

No build step is required because this is a static HTML/CSS project.
